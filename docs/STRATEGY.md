# Strategy Brief

Research thesis: a public information event can create a temporary repricing impulse. The event is a catalyst; market microstructure is the confirmation layer.

```text
public event -> relevance -> novelty -> market response -> private alpha -> short-lived position -> exit
```

Market confirmation can use ten-level depth, trade-flow state, spread/liquidity, short return, pressure and temporal state.

Do not use keyword matches as standalone trading signals. Public events can be duplicated, stale, deleted, clarified, spoofed, or already priced in.

Evaluate net PnL after fees, slippage, adverse selection, fill ratio, holding time, latency, drawdown, tail loss, turnover and regime performance. Win rate alone is insufficient.
